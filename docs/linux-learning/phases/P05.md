# P05 — 평가·채점·해설·Memory

> P05의 공개 phase 명세다. 별도의 상세 phase design이 작성되었다고 주장하지 않는다.

선행 단계: P04.

## 설계와 구현 범위

- 마지막 필수 section 완료 event로 평가 자동 준비; server가 전체 완료 재검사
- 8문항 구성과 source/question version 및 option shuffle 고정
- 답안 저장, 제출, 결정적 server 채점, 정답과 모든 오답 해설
- concept Memory, misconception, review due date, 중복 제출 원자성
- 실제 학습 section 복귀와 준비/부족/실패 UX
- 본인 challenge → 관리자 판정 → 문항 철회 → 불변 correction과 Memory 재계산

## 산출물

- 평가/결과/복습 UI
- 채점/Memory API
- P05 독립 검증 보고서

## 필수 검증 게이트

- 제출 전 API/HTML/bundle/cache에 answer/explanation 누출 없음
- 중복·동시 submit에도 score/Memory 한 번만 갱신
- 타 사용자의 attempt/job/result 접근 거부
- answer option ID와 shuffle mapping 보존, submit 뒤 answer 변경 거부
- 8문항, 6정답 진행 기준, 필수개념 복습 추천
- 학습 미완료 조기 출제 차단과 마지막 section 완료의 중복 없는 준비 job

## 제약과 중단 조건

LLM은 점수를 계산하지 않는다. 승인된 은행이 부족하면 문항 수를 줄이거나 낮은 품질 후보로 채우지 않는다.
