# P03 — 단원·섹션 학습 화면

> P03의 공개 phase 명세다. 별도의 상세 phase design이 작성되었다고 주장하지 않는다.

선행 단계: P02.

## 설계와 구현 범위

- dashboard, 7개 단원, section 화면과 선수개념/학습목표 UI
- Markdown/code/table/image safe renderer와 loading/error/alt 처리
- 사용자별 section completion과 source version 갱신 알림
- 마지막 필수 section 완료 시 user/unit/source-version 평가 준비 작업을 멱등 등록
- 준비 상태와 풀이 CTA, mobile/keyboard/focus/screen-reader, 이어 학습

## 산출물

- 단원/section UI
- 진행률 API
- 브라우저 검증 capture와 P03 독립 검증 보고서

## 필수 검증 게이트

- dashboard → section → 완료 → 새 session 복귀 E2E
- source의 script/HTML이 실행되지 않고 code 예시도 서버에서 실행되지 않음
- 이미지 실패에도 text 학습 가능, private manifest 이미지의 실제 rendering 점검
- learner A/B 진도 분리와 새 source version 재학습 표시

## 제약과 중단 조건

읽기 완료와 평가 통과를 구분한다. question/answer를 정적 frontend bundle에 넣지 않는다.
