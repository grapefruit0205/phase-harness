# P02 — Notion 동기화·이미지·RAG

> P02의 공개 phase 명세다. 별도의 상세 phase design이 작성되었다고 주장하지 않는다.

선행 단계: P01.

## 설계와 구현 범위

- Notion API pagination, nested block, bounded retry, root allowlist 수집
- source version의 `staging → active` 원자 전환과 MIME/크기/hash/SSRF 검사
- private fixture importer와 asset manifest resolver; live 수집에서만 실제 stable locator 보관
- concept/heading 단위 chunk와 pgvector 검색, version/unit/entitlement filter
- 교재 수정·삭제·권한 철회에 따른 question bank/media 접근 유효성 처리

## 산출물

- 교재 ingestion module
- media storage adapter
- authorization-filtered RAG retrieval module
- P02 독립 검증 보고서

## 필수 검증 게이트

- 중간 수집 실패, rate limit, page 누락 시 마지막 유효 버전 유지
- 만료 asset 재조회, 외부/내부망 주소 차단, local fallback, 한국어 alt 검증
- 다른 단원·버전·권한 밖 source 검색 누출 없음
- 17페이지 fixture ingest와 40개 image association 확인; 그림 내용/가독성은 별도 시각 검토 기록

## 제약과 중단 조건

서명 URL을 fixture, DB 영구 식별자, API 응답, log, frontend bundle에 넣지 않는다. P00–P06에서는 실제 Notion token 없이 fake provider로 검사한다.
