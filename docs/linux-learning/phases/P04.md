# P04 — 자동 생성과 문제 품질 은행

> P04의 공개 phase 명세다. 별도의 상세 phase design이 작성되었다고 주장하지 않는다.

선행 단계: P03.

## 설계와 구현 범위

- LangGraph의 제한 상태 흐름과 Bedrock adapter
- 단원 blueprint, structured draft, 규칙 검사, 독립 reviewer, 보류/게시 상태
- source ID/hash, duplicate, distractor misconception, 보기별 설명, 환경조건 검사
- DB outbox → SQS worker/DLQ, idempotency, retry/cost limit
- 관리자 교육 검토 UI와 audit; 승인 없는 fixture/candidate의 자동 게시 차단

## 산출물

- 생성 worker와 상태 machine
- question bank와 관리자 검토 UI
- negative fixture/eval harness와 P04 독립 검증 보고서

## 필수 검증 게이트

- 보기 4개, 정답 1개, 모든 보기 설명, 실제 source 근거 검증
- 두 정답, 조건 누락, 근거 조작, source prompt injection, 범위 밖 입력 quarantine
- `review_pending`, 은행 부족, 생성 중, 실패 상태 구분
- 중복 queue 전달, model timeout, 비용 한도, 교정 2회 초과 재현

## 제약과 중단 조건

fake 성공을 실제 model 정확도로 주장하지 않는다. 첫 운영 release의 모든 전달 문항은 사람 교육 검토를 요구한다.
