# P01 — 애플리케이션 뼈대와 인증

> 공개용 phase 명세다. [P01 상세 설계](../design/P01-detailed-design.md)는 구현 목표이며 이 문서는 현재 완료 상태를 주장하지 않는다.

선행 단계: P00.

## 설계와 구현 범위

- `apps/web` React/TypeScript/Vite, `apps/api` FastAPI, `apps/worker`, 공통 domain package 구성
- PostgreSQL+pgvector local containers, migration, 시작 설정 검증, fake source/model adapter
- live Cognito adapter와 local fake identity 경계, course membership, learner/admin 서버 인가
- same-origin BFF, HttpOnly session, CSRF, `token_use`/`client_id` JWT 검증
- lint/typecheck/build/test 명령, CI, 재현 가능한 lockfile

## 산출물

- web/API/worker와 공통 package
- local compose와 migration
- P01 상세 설계 및 독립 검증 보고서

## 필수 검증 게이트

- 한 명령 local 기동과 health/readiness 성공
- 미인증, 타 사용자, 관리자 권한 상승, production fake identity 거부
- frontend/API build, 새 DB migration, downgrade/re-upgrade, 단위·통합·브라우저 검사
- production artifact와 container에 source/정답/secret이 없는지 검사

## 제약과 중단 조건

실제 로그인 계정 없이 auth 계약을 암호학적 test key와 mock transport로 검증한다. AWS resource를 만들지 않으며 live provider 성공을 주장하지 않는다.
