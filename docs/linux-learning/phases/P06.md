# P06 — 통합·보안·교육 평가

> P06의 공개 phase 명세다. 별도의 상세 phase design이 작성되었다고 주장하지 않는다.

선행 단계: P05.

## 설계와 구현 범위

- local 전체 E2E와 CI required check 정리
- 단원별 positive/negative quality set, model review와 human educational review 분리
- 보안 경계, 비용 제한, retry, 권한 철회, 개인정보 삭제 통합 검사
- 동시 submit/completion, outbox replay, 문항 철회, Memory 재계산, session/CSRF 회귀
- 실제 화면 시각/접근성/실패 UX 점검
- 배포 전 알려진 한계, 교육 보강, 실제 provider 미검증 범위 기록

## 산출물

- end-to-end tests
- quality evaluation data와 결과
- P06 독립 검증 및 deployment-readiness 문서

## 필수 검증 게이트

- 각 7개 단원에서 최소 10개의 invalid candidate가 규칙/검토 경로에서 보류됨
- gold/reference fixture는 human-review-required 상태를 유지하고 fake score와 실제 quality를 구분
- 학습 → 평가 → 결과 → 복습 E2E와 cross-user/answer-leak 회귀 0
- build/lint/typecheck/backend/browser test의 실제 실행 결과와 revision 기록
- critical/high security defect 0 또는 release 차단 상태

## 제약과 중단 조건

실제 Bedrock/Notion 연결은 이후 deployment phase에서 검증한다. local 통과를 production 완료로 표현하지 않는다.
